## Особенности

- **Быстрое пополнение без регистрации** — покупка за 3 клика прямо на главной странице
- **Три типа товаров**: Account Top-Up, Voucher/Key Delivery, Gift Card / Wallet
- **Прозрачное ценообразование** — сумма и комиссия (10%) до оплаты
- **Оплата картой или СБП** — при выборе карты: ввод номера, держателя, срока, CVV; переворачивающаяся карта-превью, определение типа (МИР / Visa / Mastercard)
- **Чат с поддержкой** — плавающая кнопка, открытие из FAQ и личного кабинета; история в sessionStorage
- **Переписка по заказу** — на странице статуса заказа: лента сообщений с поддержкой, сохранение истории, имитация ответов оператора
- **Адаптивный дизайн** — desktop (1440px) и mobile (390px)
- **Админ-панель** — товары, заказы, ценообразование, тикеты поддержки
- **Светлая тема** — современный fintech/gaming дизайн

## 🛠 Технологии

### Frontend Stack
- **React 18.3** — UI библиотека
- **TypeScript** (strict mode) — строгая типизация
- **Vite 6.3** — сборщик и dev-сервер
- **React Router DOM 7** — маршрутизация с code splitting
- **Tailwind CSS 4** — стилизация
- **Shadcn UI** — компоненты на базе Radix UI
- **Motion** — анимации
- **Sonner** — уведомления (toast)
- **Lucide React** — иконки

### State Management & Validation
- **Zustand** — глобальное состояние (аутентификация)
- **Zod** — runtime валидация форм и API ответов
- **React Hooks** — кастомные хуки для данных

### UI Компоненты
- Radix UI примитивы (Dialog, Select, Accordion, Tabs, Sheet и др.)
- Кастомные компоненты в стиле Shadcn (в т.ч. `credit-debit-card` — переворачивающаяся карта при вводе данных оплаты)
- Адаптивная сетка и layout
- Bento-стиль для инструкций
- Code splitting через React.lazy()

- npm или pnpm

npm install

или

pnpm install

## Интеграция с Backend

Проект готов к интеграции с backend API. Все сервисы автоматически переключаются между mock и real API на основе конфигурации.

### Демо-режим

**По умолчанию включен** в development для удобной разработки без backend:
- Все данные берутся из `src/app/data/mockData.ts`
- Визуальный индикатор демо-режима в header
- Автоматически отключается в production

**Как отключить демо-режим:**
```bash
# Создать .env файл
VITE_USE_MOCK_DATA=false
VITE_API_URL=https://api.zvezda.ru
```

### API Endpoints (ожидаемые)

```
# Публичные
GET    /api/products              - Список товаров
GET    /api/products/:slug        - Детали товара по slug
GET    /api/products/by-id/:id    - Детали товара по ID
POST   /api/orders                - Создание заказа
GET    /api/orders/:id            - Статус заказа
GET    /api/user/orders           - Заказы пользователя
POST   /api/payment               - Инициализация платежа
GET    /api/payment/:id/status    - Статус платежа

# Аутентификация
POST   /api/auth/login            - Вход
POST   /api/auth/register         - Регистрация
POST   /api/auth/refresh          - Обновление токена
POST   /api/auth/logout           - Выход

# Админ
GET    /api/admin/orders           - Заказы (админ)
GET    /api/admin/orders/:id      - Детали заказа (админ)
PUT    /api/admin/orders/:id      - Обновление заказа
GET    /api/admin/stats            - Статистика
```

### Архитектура интеграции

**Слои:**
1. **API Client** (`src/app/api/client.ts`) — централизованный HTTP клиент с:
   - Retry логикой (exponential backoff)
   - Обработкой ошибок
   - Таймаутами
   - Автоматической авторизацией

2. **Services** (`src/app/services/`) — бизнес-логика:
   - Автоматическое переключение mock/real API
   - Runtime валидация ответов через Zod
   - Типизированные методы

3. **Hooks** (`src/app/hooks/`) — React хуки для данных:
   - `useProducts` — товары
   - `useOrders` — заказы
   - `useAuth` — аутентификация

4. **Components** — UI компоненты используют хуки

### Runtime валидация API

Все ответы API валидируются через Zod схемы (`src/app/types/schemas.ts`):
- Гарантия соответствия типов
- Логирование ошибок валидации
- Понятные сообщения об ошибках

### Переменные окружения

```bash
# .env
VITE_API_URL=https://api.zvezda.ru    # URL backend API
VITE_USE_MOCK_DATA=false              # Отключить демо-режим
```
